# Clinica-Veteriniria-MVC

# 🐾 Sistema de Gestão de Clínica Veterinária

Este sistema foi desenvolvido com o objetivo de gerenciar uma clínica veterinária de forma eficiente, intuitiva e completa. Com ele, é possível registrar e controlar todas as informações importantes sobre os pets, seus tutores, os veterinários e as consultas realizadas.

## 💡 Funcionalidades Principais

- **Cadastro de Pets**: Armazene dados completos dos animais, como nome, raça, idade, sexo, peso, estado reprodutivo e tutor responsável.
- **Histórico de Vacinas**: Visualize e acompanhe as vacinas aplicadas em cada pet.
- **Cadastro de Tutores**: Registre os tutores com seus dados de contato e gerencie os pets associados a eles.
- **Cadastro de Veterinários**: Mantenha o controle sobre os profissionais da clínica, suas especialidades e horários disponíveis.
- **Consultas**: Agende e gerencie consultas entre pets, tutores e veterinários com data, horário e categoria.
- **Relatórios e Informações**: Exiba os dados de forma organizada para melhor acompanhamento da saúde dos animais.

## 🧠 O que eu aprendi desenvolvendo esse sistema

Desenvolver este sistema foi uma experiência extremamente enriquecedora. Ao longo do projeto, pude aprender e aplicar:

- A estruturação de um sistema orientado a objetos com múltiplas classes interligadas.
- O uso de **Java Swing** para criar interfaces gráficas com `JPanel`, `JFrame` e outros componentes visuais.
- Como persistir dados usando **JDBC** e integrar com o banco de dados H2.
- A importância do **design modular**, com separação entre modelos, controle e interface.
- A criação de métodos para operações **CRUD** (Criar, Ler, Atualizar e Deletar) para diferentes entidades.
- Como pensar em **experiência do usuário**, organizando o sistema com janelas intuitivas.
- A lógica de relacionamentos entre entidades como pet, tutor e veterinário.
- Gerenciar e exibir **dados relacionados**, como histórico de peso dos pets e suas vacinas.
- Planejamento de melhorias futuras, como relatórios, segurança e integração com outras ferramentas.
